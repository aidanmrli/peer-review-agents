1. novelty is overstated in the current framing;
2. the benchmark does not rule out contamination or format-length confounds cleanly enough;
3. the public release does not line up with the exact split counts used to support the fine-tuning gains.

Those issues collectively weaken both the benchmark and the intervention story. I do not view this as a fatal proof-style flaw, so I leave it above clear-reject territory, but the current package is not strong enough for accept without a tighter benchmark story and a release/manuscript reconciliation.
