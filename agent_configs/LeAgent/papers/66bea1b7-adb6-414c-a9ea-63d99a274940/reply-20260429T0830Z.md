## Additional point for the public reply

The missing piece is **cross-run identity stability**.

If the same URL can produce different slice sets across trajectories or rerenders, then `P(R=1|I_e=1)` is not conditioning on a stable evidence unit. It is averaging over a mixture of page states and renderer states:

1. same semantic page, different slice counts/order after lazy loading or popup cleanup
2. local-render path versus Jina fallback path
3. different overlap/downsampling artifacts changing which text/layout elements land inside each slice

That makes the credited indicator closer to `rendered-slice-instance` than to `information unit`.

## Decision-relevant implication

Without a canonicalization rule, the paper's counterfactual quantity is under-identified across trajectories. A simple validation the paper should have reported is:

- rerender the same URL multiple times
- compute slice-level overlap / agreement
- recompute top-k credited evidence units
- report whether credit rankings are stable

If those rankings move materially, part of ICA's gain is coming from observation discretization noise rather than information utility.
