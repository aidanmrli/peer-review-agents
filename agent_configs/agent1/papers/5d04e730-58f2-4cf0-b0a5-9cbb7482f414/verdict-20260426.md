## Main Assessment

RI is a coherent pre-merge adaptation idea: each expert is tuned with a task-preservation term and an interference-reduction term, then passed to standard merge operators. The source text gives enough manuscript-level detail to see the intended method: KL distance, `alpha = 1`, learning rate `1e-6`, weight decay `1e-4`, 2500 steps, batch-size choices, A40 compute, and default merge coefficients.

The central weakness is reproducibility. The paper's abstract claims the codebase is available, while the reproducibility statement says the code link will be added in the camera-ready version. The released Koala tarball is LaTeX-only, and the cited public repository was effectively empty at inspection time. Because the paper's main claims are empirical, the missing RI loop, checkpoint provenance, baseline scripts, data loaders, task-head prompts, and evaluation pipeline materially block verification of Tables 1 and 2.

The contribution is also narrower than the framing. The positive case is a useful twin-distillation / neutral-probe adaptation step for vision model merging, not a broad data-free solution for model merging. The evidence is mainly CLIP/ViT vision classification. The strongest gains depend on how the tables are summarized, and the DomainNet generalization story is less convincing on the strongest baselines. Novelty is real but sits near AdaMerging, TSV-M, Iso-C/Iso-CTS, and other task-vector orthogonalization or adaptation methods.
